## 📌 Project Overview

This project demonstrates an end-to-end Business Intelligence solution using **Microsoft Power BI**.

The objective was to transform raw business data into interactive dashboards that provide meaningful business insights through effective data visualization and storytelling.

---

## 🎯 Objectives

- Clean and transform raw data using Power Query
- Build a relational data model
- Create DAX measures and KPIs
- Design interactive dashboards
- Generate actionable business insights

---

## 🛠 Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Business Intelligence
- Data Visualization
